# Morning Timer v2.4-a.3 — Changelog

## Изменено

### Экран выхода

Экран `Выхожу / Вернуться` больше не открывается просто по окончанию таймеров.

Теперь условие выхода:

```text
все 12 чекбоксов отмечены
```

## Добавлено

### Копилка как утренний лимит

Копилка теперь работает как оставшееся глобальное время:

```text
утренний лимит + сэкономленное время - прошедшее время
```

Когда копилка заканчивается, появляется режим:

```text
Опоздание +MM:SS
```

## Добавлена графика

На экран выхода добавлена графика довольного ребёнка с рюкзаком в мягком flat/emoji-стиле.

## Проверить

1. Включить `684100`.
2. Отметить не все задачи.
3. Дождаться окончания всех таймеров.
4. Убедиться, что экран выхода не появляется до отметки всех чекбоксов.
5. Отметить оставшиеся чекбоксы.
6. Убедиться, что экран выхода появляется.
