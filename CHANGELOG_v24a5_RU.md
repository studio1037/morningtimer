# Morning Timer v2.4-a.5 — Changelog

## Исправлено

### Копилка времени

Было:

- копилка появлялась и ежесекундно обновлялась.

Стало:

- копилка статична;
- появляется только при первом накоплении сэкономленного времени;
- увеличивается только при новом досрочном завершении этапа;
- посекундное обновление включается только в режиме `Опоздание`.

## Формула

```text
копилка = сумма сэкономленного времени этапов
опоздание = прошедшее реальное время - (утренний лимит + копилка)
```

Если опоздание меньше или равно нулю — показываем статичную копилку.
Если опоздание больше нуля — показываем `Опоздание +MM:SS`.
