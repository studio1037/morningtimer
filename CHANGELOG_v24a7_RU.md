# Morning Timer v2.4-a.7 — Changelog

## Исправлено

### Критическая ошибка v2.4-a.6

В `v2.4-a.6` функция `visibleBankAmount()` ошибочно вызывала сама себя:

```js
var bank = visibleBankAmount();
```

Из-за этого ломался `render()`:

- таймеры переставали обновляться;
- копилка не появлялась;
- интерфейс обновлялся только при новом клике.

## Исправление

Теперь `visibleBankAmount()` использует базовую сумму копилки:

```js
var bank = bankAmount();
```

Также `lateElapsed()` использует полную сумму копилки, а не видимое значение.

## Ожидаемое поведение

- таймеры снова идут сами;
- копилка появляется после накопления;
- до окончания последнего этапа копилка статична;
- после окончания последнего этапа копилка уменьшается посекундно;
- после нуля включается `Опоздание`.
