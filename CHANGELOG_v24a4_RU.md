# Morning Timer v2.4-a.4 — Changelog

## Pro-бенефиты финализированы

Список Pro-функций:

1. Профили детей.
2. Рубрикатор задач и иконок.
3. Изменение количества этапов.
4. Изменение длительности этапов и общего утреннего лимита.
5. Изменение количества задач внутри этапов.
6. Шаблоны сценариев.
7. Отчёты для родителя.

## Технические изменения

- Кнопка Morning Timer Pro в настройках теперь прокручивает экран к разделу Pro-настроек.
- Раздел Pro-настроек расширен.
- Исправлено склеивание заголовка и пояснения в строках Pro-настроек.
- Добавлен код `684168` для включения/выключения Pro-режима.

## Код Pro

```text
684168
```

Повторный ввод кода выключает Pro-режим.
