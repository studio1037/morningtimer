# Morning Timer — названия сущностей приложения

## 1. Продуктовые уровни

### App / Приложение
**Morning Timer**  
Общее название приложения.

### Routine / Сценарий
**Утренний сценарий**  
Полный маршрут ребёнка от первого действия до выхода.

### Run / Запуск
**Утренний запуск**  
Одна конкретная утренняя сессия.

### Global Time / Глобальное время
**Утренний лимит**  
Общее условное время, которое начинается с первого отмеченного чекбокса.

---

## 2. Главные экраны

### Home Screen
**Главный экран**  
Экран с четырьмя этапами, таймерами, задачами и копилкой.

### Exit Gate
**Экран выхода**  
Экран `Выхожу / Вернуться`.

### Result Screen
**Экран результата**  
Экран с итогом: сэкономленное время или опоздание.

### Settings Screen
**Настройки**  
Родительская зона.

### Task Editor Screen
**Редактор задач**  
Экран настройки задач и смайликов.

### Emoji Picker Screen
**Выбор иконки**  
Экран выбора emoji для задачи.

### Pro Screen
**Pro-экран**  
Экран объяснения платных возможностей.

### Install Screen
**Экран установки**  
Инструкция по добавлению PWA на экран Домой.

---

## 3. Этапы

### Stage
**Этап**  
Один из 4 крупных блоков утра.

### Default Stages

1. **Начальные ритуалы**
2. **Одевание**
3. **Завтрак**
4. **Подготовка к выходу**

### Stage Timer
**Таймер этапа**  
Таймер конкретного этапа.

### Stage Completion
**Завершение этапа**  
Состояние, когда этап закрыт по задачам или по времени.

---

## 4. Задачи

### Task
**Задача**  
Одна маленькая визуальная задача внутри этапа.

### Task Icon
**Иконка задачи**  
Emoji / визуальный символ задачи.

### Task Label
**Автоподпись задачи**  
Текстовая подпись, автоматически связанная с emoji.

### Checkbox State
**Отметка задачи**  
Состояние: выполнено / не выполнено.

### Checklist
**Чек-лист этапа**  
Три задачи внутри одного этапа.

---

## 5. Награды и время

### Saved Time
**Сэкономленное время**  
Время, оставшееся на этапе после выполнения всех задач.

### Achievement Badge
**Бейдж достижения**  
Плашка `🏆 +MM:SS` на завершённом этапе.

### Savings Bank
**Копилка времени**  
Верхняя плашка с суммой сэкономленного времени.

### Late Time
**Опоздание**  
Время сверх утреннего лимита.

---

## 6. Настройки и Pro

### Free Emoji Library
**Общая библиотека смайликов**  
Единый набор emoji для всех этапов во Free-версии.

### Pro Rubricator
**Pro-рубрикатор**  
Фильтр смайликов по рубрикам в Pro-версии.

### Rubrics / Рубрики

1. **Гигиена**
2. **Одежда**
3. **Еда**
4. **Выход**
5. **Другое / универсальное**

### Template
**Шаблон задач**  
Предустановленный набор иконок.

### Default Templates

1. **Классика**
2. **Школа**
3. **Сад**
4. **Быстро**

---

## 7. Служебные сущности

### Reset Code
**Код сброса**  
`684`

### Test Mode Code
**Код тестового режима**  
`684100`

### Turbo Mode
**Тестовый режим**  
Ускоренный режим проверки финальных экранов.

---

## 8. Рекомендованная терминология в интерфейсе

Использовать:

- `Редактор задач`, не `Редактор иконок`
- `Иконка задачи`, не `картинка`
- `Автоподпись`, не `название смайлика`
- `Копилка времени`, не `общий счётчик`
- `Бейдж достижения`, не `плашка`
- `Утренний лимит`, не `глобальный таймер`
- `Pro-рубрикатор`, не `категории смайликов`

## 9. Будущий апгрейд

**Анимация копилки**  
Сэкономленные минуты перелетают в сундук / сейф / копилку после нажатия `Выхожу`.
