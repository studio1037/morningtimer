# Morning Timer v2.9 Stable

Самая стабильная утверждённая сборка.

## База

Собрана от стабильной ветки v2.4-a.8 + логика v3.0.1 rebuilt.

## Ключевая стабильная логика

Если этап уже завершён и его остаток ушёл в копилку, но пользователь снимает чекбокс из этого этапа:

- этап снова становится активным;
- сохранённое время этого этапа удаляется из копилки;
- таймер этапа продолжает идти с этого остатка.
