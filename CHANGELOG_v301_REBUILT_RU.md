# Morning Timer v3.0.1 Rebuilt — Changelog

Собрано от стабильной `v2.4-a.8`.

## Добавлено

Если пользователь снимает чекбокс из уже завершённого этапа:

- этап возвращается в активное состояние;
- сохранённое время этого этапа удаляется из копилки;
- таймер этапа продолжает отсчёт с сохранённого остатка.
