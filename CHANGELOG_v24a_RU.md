# Morning Timer v2.4-a — Changelog

## Добавлено

1. Автоматическая подпись к выбранному emoji.
2. Ручное редактирование подписи не добавлялось намеренно.
3. Emoji-label map для RU / EN / HE.
4. Расширенная emoji-библиотека.
5. Шаблоны задач:
   - Классика;
   - Школа;
   - Сад;
   - Быстро.
6. Кнопка сброса иконок к дефолтному набору.

## Изменено

- Редактор задач теперь работает по принципу:
  `emoji = смысл = автоматическая подпись`.

## Причина

Чек-листы усилили интерактивность, поэтому настройка визуальных микрозадач становится ключевой частью продукта.
