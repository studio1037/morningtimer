# Morning Timer v2.4-a.2 — Changelog

## Исправлено

### Post-timeout checklist completion

Если время закончилось, пользователь вернулся с экрана `Выхожу / Вернуться` на главный экран и затем отметил все оставшиеся чекбоксы, приложение автоматически снова открывает экран `Выхожу / Вернуться`.

## Уточнено

### Free

Во Free-версии все этапы используют единый общий набор смайликов.

### Pro

В Pro-версии предполагается рубрикатор, который:
- фильтрует смайлики по категории;
- расширяет количество доступных смайликов.

Рубрики:
- гигиена;
- одежда;
- еда;
- выход;
- другое / универсальное.

В текущей сборке Pro-рубрикатор показан как залоченный слой.
