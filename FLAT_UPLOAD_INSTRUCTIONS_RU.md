# Morning Timer v2.2-c Flat — инструкция загрузки

Эта версия собрана без подпапок. Все файлы должны лежать в корне GitHub-репозитория.

## Что загрузить

Загрузить все файлы из архива прямо в корень репозитория:

```text
index.html
manifest.json
service-worker.js
README.md
BRANDING_SOCIAL_INSTALL_NOTES.md
FLAT_UPLOAD_INSTRUCTIONS_RU.md
apple-touch-icon.png
icon-192.png
icon-512.png
maskable-icon-512.png
og-preview-1200x630.png
install-card-ru-1080.png
install-card-en-1080.png
install-card-he-1080.png
```

## Важно

Не создавать папку `social-assets`.

В этой flat-версии все ссылки переписаны на корневые файлы:

```text
./og-preview-1200x630.png
./install-card-ru-1080.png
./install-card-en-1080.png
./install-card-he-1080.png
```

## После загрузки

Открыть GitHub Pages ссылку с параметром версии, чтобы обойти кэш:

```text
?v=22c-flat
```
