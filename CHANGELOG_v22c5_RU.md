# Morning Timer v2.2-c.5 — Changelog

## Исправлено

### Баг
После окончания времени пользователь нажимал `Выхожу`, попадал на экран результата, затем нажимал возврат. Но поскольку все таймеры уже были `00:00`, приложение снова автоматически открывало экран `Выхожу / Вернуться`.

### Решение
Добавлен флаг `dismissedExit`.

Теперь:
- автоматический экран выхода открывается один раз;
- если пользователь вручную вернулся на главный экран, приложение не затягивает его обратно;
- сброс по `684` очищает флаг;
- сервисный режим `684100` очищает флаг.
